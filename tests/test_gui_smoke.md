# Testy GUI i eksportu

Test manualny po uruchomieniu `python main.py`:

1. Wczytaj `data/test_01_przecinek.csv` i sprawdź podgląd oraz profil.
2. Wczytaj `data/test_02_srednik.csv` i potwierdź poprawną liczbę kolumn.
3. Na `test_03_braki_duplikaty.csv` wybierz medianę, usuń braki i duplikaty.
4. Na `test_04_zakres_outlier.csv` sprawdź wykrycie wartości -5 i 1000.
5. Zbuduj histogram, scatter, box plot i bar plot.
6. Zapisz `cleaned.csv`, raport CSV oraz wykresy PNG i PDF/SVG.
7. Ponownie wczytaj zapisane pliki i potwierdź brak błędów formatu.
